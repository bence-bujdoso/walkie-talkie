SOURCE 6: I/Q Architecture Technical Analysis
--------------------------------------------------------------------------------
Source: BK4819 datasheet, DSP literature

BK4819 Architecture:
  - Low-IF image rejection architecture
  - Quadrature mixer generates I and Q signals
  - Separate ADCs for I and Q channels
  - Digital IF processing for FM demodulation

Purpose of I/Q in BK4819:
  "Low-IF image rejection architecture is implemented in order to
   eliminate the external SAW filters."

Key Finding: I/Q used for IMAGE REJECTION, not SSB modulation

Why I/Q Doesn't Enable SSB:
  1. I/Q mixers necessary but NOT sufficient
  2. Missing: Hilbert transform audio processing
  3. Missing: Sideband selection filters
  4. Missing: Carrier suppression circuitry
  5. PA is non-linear (Class C/E for FM efficiency)

Quote from technical literature:
  "To realize acceptable sideband suppression, the 90° phase shift for
   the LO and the 90° shift between I and Q, as well as their amplitude
   have to be matched exactly. This is hardly practical with analog
   components."

SOURCE 7: SSB Generation Requirements
--------------------------------------------------------------------------------
Source: Technical articles, DSP textbooks

SSB Generation Methods:

1. Filter Method:
   Audio → Balanced Modulator → Crystal Filter (USB or LSB) → Mixer → PA

   Requirements:
     - Balanced modulator: >40 dB carrier suppression
     - Crystal filter: >60 dB opposite sideband rejection
     - Linear PA: Class A or AB

   BK4819 Has: NONE of these

2. Phasing Method:
   Audio ────────────────────→ I Modulator ─┐
   Audio → Hilbert Transform → Q Modulator ─┴→ Summer → PA

   Requirements:
     - Hilbert transform: 90° audio phase shift
     - I/Q balance: <1% amplitude, <1° phase error
     - Linear PA: Class A or AB

   BK4819 Has: I/Q mixers only (missing audio processing)

Conclusion: BK4819 lacks components for BOTH SSB methods

   - No carrier suppression circuitry
   - I/Q used for image rejection, not SSB generation
   - Conclusion: Wrong hardware for SSB

3. CHIP DESIGN INTENT (Official)
   - Datasheet: "Half-duplex TDD FM transceiver"

6. I/Q MISCONCEPTION (Technical)
   - I/Q present but used for FM image rejection
   - I/Q necessary but NOT sufficient for SSB
   - Missing: Audio Hilbert transform
   - Missing: Sideband filters
   - Missing: Balanced modulator
   - Conclusion: I/Q doesn't enable SSB on this chip

7. DSP CAPABILITIES (Limited)
   - DSP optimized for FM discriminator
   - DSP handles CTCSS/DCS decoding
   - No Hilbert transform FIR filters
   - No sideband selection processing
   - Conclusion: Wrong DSP algorithms for SSB

   - Class C or Class E (non-linear)

   - High efficiency (~60%) for FM

   - Conclusion: PA fundamentally wrong for SSB
