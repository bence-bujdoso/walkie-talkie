================================================================================
WHY CW EXISTS BUT NOT USB/LSB
================================================================================

CW (Continuous Wave / Morse Code):
  - Simple on/off keying of carrier
  - Minimal DSP requirements
  - ~5-10 KB of code
  - Easy to implement

USB/LSB (Single Sideband):
  - Complex Hilbert transform required
  - I/Q modulation needed
  - Sophisticated filtering
  - ~100-200 KB of DSP code
  - Difficult to implement

CONCLUSION: Firmware includes easy modes (CW), excludes hard modes (SSB).
