MODE SWITCHING FLOW
================================================================================

1. User selects mode → Read mode_byte (0-4)
2. Firmware validates mode:
   - IF mode == 0x00 (FM):  Valid, RX+TX
   - IF mode == 0x01 (AM):  Valid, RX+TX
   - IF mode == 0x04 (CW):  Valid, RX only
   - IF mode == 0x02/0x03:  INVALID (not implemented)
3. Check TX permission:
   - mode_bit = (1 << mode_byte)
   - IF (mode_bit & 0x03): TX allowed
   - ELSE: TX blocked, show "DISABLE"
4. Enable/disable PTT accordingly
