TX UNLOCK PROCEDURE:
════════════════════════════════════════════════════════════════════════════

METHOD 1: Hex Editor (Manual)
──────────────────────────────
1. Calculate channel offset:
   Offset = Channel_Number × 64 (decimal)
   Example: Channel 1044 = 1044 × 64 = 66,816 = 0x10500

2. Add 22 to get TX permit byte:
   TX_Byte_Offset = Channel_Offset + 22
   Example: 0x10500 + 0x16 = 0x10516

3. Change byte value:
   0x00 → 0xFF (disabled to enabled)

4. Save and test with dummy load!


METHOD 2: Python Script (Automated)
────────────────────────────────────
Run: python detailed_channel_analysis.py

Output: TK11_TX_UNLOCKED.dat
  - Automatically finds all valid channels
  - Sets Byte 22 = 0xFF for all active channels
  - Preserves all other data

FREQUENCY DECODING:
════════════════════════════════════════════════════════════════════════════

Format: 32-bit Little-Endian Integer (Hz)

Example 1:
  Hex bytes:     44 C9 29 00
  Read as LE:    0x0029C944
  Decimal:       2,738,500
  Frequency:     2.7385 MHz

Example 2:
  Hex bytes:     70 7F BF 00
  Read as LE:    0x00BF7F70
  Decimal:       12,550,000
  Frequency:     12.55 MHz

Example 3:
  Hex bytes:     80 02 75 03
  Read as LE:    0x03750280
  Decimal:       58,000,000
  Frequency:     58.00 MHz (FM Broadcast - LOCKED!)

Python code:
  import struct
  freq_hz = struct.unpack('<I', bytes.fromhex('44c92900'))[0]
  freq_mhz = freq_hz / 1_000_000
  print(f"{freq_mhz:.4f} MHz")

CHANNEL OFFSET CALCULATOR:
════════════════════════════════════════════════════════════════════════════

  Offset (hex) = Channel × 0x40
  Offset (dec) = Channel × 64

  Ch    0 → 0x00000000 (0)
  Ch    1 → 0x00000040 (64)

  Ch  100 → 0x00001900 (6400)
  Ch 1000 → 0x0000FA00 (64000)

TX Byte Offset = Channel Offset + 0x16 (22 decimal)
