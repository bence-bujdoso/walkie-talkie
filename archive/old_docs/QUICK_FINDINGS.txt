================================================================================
WHY DOES CW EXIST BUT NOT USB/LSB?
================================================================================

CW (Morse code) is simpler than SSB:
  - CW = Just turn carrier on/off (keying)
  - CW = No complex DSP required
  - CW = Minimal code overhead

SSB requires:
  - Hilbert transform for sideband generation
  - I/Q modulation
  - Complex filtering
  - Significant DSP code
  - More CPU/memory resources

Conclusion: Firmware has CW because it's easy. No SSB because it's hard.
